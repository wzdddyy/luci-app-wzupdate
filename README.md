# luci-app-wzupdate

给 [iStoreOS-NN6000](https://github.com/wzdddyy/iStoreOS-NN6000) 提供在线更新固件的 LuCI 插件。

iStoreOS-NN6000已于2026-11-20之后的版本内置了此插件，无需单独安装。

专用插件，非此固件请勿下载安装。

分区包含HLOS_1，rootfs_1分区，才能使用此插件更新。

或使用推荐分区镜像，详见 [分区说明](https://github.com/wzdddyy/iStoreOS-NN6000/blob/main/partition/README.md)。
